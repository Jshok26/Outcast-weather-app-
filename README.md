
OutcastShell is a weather planning application. The project explores how HTML, CSS, JavaScript, and the Open-Meteo Weather Forecast API can be used together to retrieve and present weather information that supports everyday planning.
Project status: in progress.

Technologies
- HTML: Page structure
- CSS: Styling and layout
- JavaScript: Application logic and API requests
- Open-Meteo Weather Forecast API: Weather forecast data


The goal of this project is to practice front-end web development and working with external data. It also explores how weather information can be made accessible and useful to people planning daily activities.
Project Files
This project has provided an opportunity to practice front-end development, working with HTTP/JSON API data, debugging, and presenting information to users. It reflects my interest in applying programming concepts to practical problems.
Data Source
Weather data: Open-Meteo.
